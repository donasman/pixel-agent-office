Watch your Claude Code agents at work.

A pixel-art office for your sessions. The main agent is the boss and every subagent is a staff member: they wake up, work at their desks, and fly their reports back to the boss. Live.

Install

npx pixel-agent-office

Node.js 18 or later. The first run offers to install the Claude Code plugin: press Enter. Then use Claude Code as usual, in any terminal or IDE.

/plugin marketplace add donasman/pixel-agent-office
/plugin install agent-office@agent-office

Run these inside Claude Code, then open the office with npx pixel-agent-office. On Windows without Git, install agent-office-powershell@agent-office instead.

git clone https://github.com/donasman/pixel-agent-office
cd pixel-agent-office
npm install
npm start

Windows only. Claude in terminal tabs on the left, the office on the right. No plugin needed.

    Answer permission prompts

    A “?” bubble and a chime when claude asks. Allow or deny from the office; whichever you answer first, office or terminal, wins.

    Spot stuck tools

    A command that runs five minutes without a sound gets flagged, on its desk and on its floor tab.

    Context and usage gauges

    How full the boss's context is, and how much of your 5-hour and weekly limits you've used.

    One floor per session

    Run several claudes at once. Each gets its own floor, named after its folder.

    Agent teams

    Teammates get desks on the lead's floor, and wake at the same desk when given more work.

    How it works

    01Claude Coderuns as usual
    02Plugin hookssend each event
    03Local serveron 127.0.0.1
    04Office windowdraws it

    Everything stays on your machine. The hooks make no model calls and cost no tokens, and they do nothing while the office is closed.

    FAQ

    Does it cost tokens or slow claude down?
    No. The hooks pass events to a server on your computer, in the background. The one exception is the permission hook, which waits for your answer, and only while the office is open.
    Is my code sent anywhere?
    No. The server listens on 127.0.0.1 only, and the office page runs in your own browser.
    What do I need?
    Claude Code and Node.js 18 or later. Tested on Windows; macOS and Linux use the same bash hooks.
    How do I remove it?
    Run /plugin uninstall agent-office@agent-office in Claude Code and delete the ~/.agent-office folder.
